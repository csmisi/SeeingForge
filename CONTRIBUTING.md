# Contributing

SeeingForge currently develops through maintainer-approved feature requests. Describe your workflow, desired behavior, and alternatives using the Feature request issue template. Submission does not guarantee implementation or a timeline.

Unsolicited implementation pull requests are not currently accepted. Discuss a feature request and obtain maintainer agreement before writing code for inclusion. GitHub can still allow pull requests to be opened; maintainers may close them under this policy.

Everyone may inspect, use, build, modify, and fork the code under GPL-3.0-or-later. This policy governs inclusion in the official repository, not rights granted by the license.

Approved contributions should explain behavior, include appropriate verification, disclose material AI assistance, and state which platforms were actually tested. Never include private recordings, access tokens, or build outputs.
